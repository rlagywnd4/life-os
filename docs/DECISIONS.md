# Decisions

## 2026-07-15

- 빈 작업공간이므로 `life-os/` 하위에 새 Next.js 앱을 생성했다.
- 초기 버전은 1단계와 2단계의 핵심 흐름을 우선 구현하고, 고급 편의 기능은 문서화된 제한으로 남겼다.
- Supabase service role key는 사용하지 않는다. 사용자 데이터 변경은 anon key + RLS + 서버 액션/RPC로 처리한다.
- Inbox -> Project 전환과 Today core action 추가는 PostgreSQL 함수로 처리해 일부 단계만 저장되는 상태를 피한다.
- Daily check-in은 하루 한 번으로 제한했다. 개인 회고 앱의 초기 버전에서는 여러 번 입력보다 날짜별 상태 추적이 더 단순하고 안정적이다.
- UI는 생산성 점수, 스트릭, 실패 문구를 만들지 않고 휴식/회복 모드를 정상 상태로 표시한다.
- PWA는 manifest와 기본 아이콘까지만 제공한다. 오프라인 수정과 동기화는 초기 범위에서 제외한다.
- RLS 자동화는 SQL 정적 테스트를 포함하고, 실제 교차 사용자 통합 검증은 Supabase 테스트 프로젝트 연결 후 수행한다.
