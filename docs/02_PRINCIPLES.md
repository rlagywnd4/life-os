# Principles

## Core Principles

1. 실행 가능성이 계획의 완성도보다 중요하다.
2. 삶의 영역은 서로 연결되어 있다.
3. 미완료, 과식, 무기력, 계획 변경을 실패로 표현하지 않는다.
4. 낮은 에너지 상태에서도 사용할 수 있어야 한다.
5. 데이터 입력 비용은 데이터 가치보다 낮아야 한다.
6. AI는 독촉보다 기억, 정리, 선택지 축소, 회고를 돕는다.
7. 먼저 한 사람에게 실제로 도움이 되게 만든 뒤 일반화한다.
8. 민감한 정보는 기본적으로 보호하고, 외부 전송은 명시적으로 다룬다.

## Non-Goals

LifeOS는 다음 제품이 되지 않는다.

- 사용자를 점수로 평가하고 죄책감을 유발하는 앱.
- 모든 행동을 기록해야 정상적으로 작동하는 앱.
- 매일 완벽한 루틴을 강요하는 앱.
- 단순한 할 일 목록 앱.
- AI가 사용자의 인생 목표를 임의로 결정하는 앱.
- 알림을 과도하게 보내는 앱.
- 한 번 세운 목표를 바꾸기 어렵게 만드는 앱.
- 민감 정보를 불필요하게 외부로 보내는 앱.
- 처음부터 다중 사용자 SaaS를 전제로 과도하게 설계된 앱.
- 칼로리 계산이 필수인 다이어트 앱.
- 연속 기록이 끊기면 성취가 무효가 되는 앱.

## Language Rules

- 성공/실패보다 상태와 변화 중심 언어를 사용한다.
- 휴식과 복귀를 정상 흐름으로 표현한다.
- AI 추론은 사실처럼 쓰지 않고 후보, 가설, 제안으로 구분한다.
