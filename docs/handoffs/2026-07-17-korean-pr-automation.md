# 2026-07-17 Korean PR Automation

Date: 2026-07-17
Status: 완료

## 작업 목표

Codex가 완료한 작업을 로컬에만 남기지 않고 한국어 커밋과 Draft PR로 자동 게시해 다른 대화와 나중 시점에도 작업 이력을 확인할 수 있게 한다.

## 구현한 내용

- 최상위 `AGENTS.md`에 Git 커밋과 PR 자동 게시 규칙을 추가했다.
- 범위가 명확하고 검증된 작업은 관련 파일만 자동 커밋·push하도록 명시했다.
- 기존 PR 갱신 또는 새 Draft PR 생성 기준을 명시했다.
- 커밋 메시지, PR 제목과 본문을 한국어로 작성하도록 고정했다.
- 사용자 요청 없이 자동 merge하거나 프로덕션 변경을 승인하지 않도록 경계를 명시했다.
- 동일한 내용을 `docs/08_CODEX_RULES.md`와 decision log에 기록했다.
- 현재 PR 제목과 본문을 한국어로 갱신한다.

## 주요 구현 결정과 이유

- 새 대화에서도 자동 적용되도록 일반 문서뿐 아니라 Codex가 우선 읽는 최상위 `AGENTS.md`에 규칙을 기록했다.
- 작업 기록과 검토 기회를 함께 유지하기 위해 새 PR은 Draft 상태를 기본으로 한다.
- 자동 merge는 Vercel 프로덕션 배포와 Supabase migration을 촉발할 수 있어 사용자 명시 요청이 있을 때만 수행한다.

- 관련 없는 사용자 변경이 섞여 있으면 자동 커밋 전에 범위 확인이 필요하다.
