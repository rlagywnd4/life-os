# Handoffs

이 디렉터리는 기능 구현 또는 분석 작업이 끝날 때마다 다음 사람이 이어받을 수 있도록 작업 단위 기록을 남기는 곳이다.

## 파일 이름

```text
YYYY-MM-DD-task-name.md
```

예:

```text
2026-07-15-diet-profile.md
2026-07-15-prd-v0.2-impact-analysis.md
```

## 작성 규칙

- 작업 하나당 파일 하나를 만든다.
- 구현자가 판단한 내용과 사용자가 실제로 느낀 피드백을 구분한다.
- PRD와 충돌하는 내용은 PRD를 직접 수정하지 말고 이 문서와 decision log에 기록한다.
- 데이터 구조나 보안에 영향이 있으면 반드시 명시한다.

## Template

```text
# 작업명

Date:
Status:

## 작업 목표

## 구현한 내용

## 변경 파일

## 데이터 구조 변경

## API 변경

## 주요 구현 결정과 이유

## 기존 PRD와 달라진 점

## 임시 구현과 기술 부채

## 실제 사용 후 확인해야 할 사항

## 남은 문제

## 다음 작업 후보

## 실행 방법

## 테스트 결과
```
