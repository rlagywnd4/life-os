# Native Secondary Features Handoff

## 작업 목표

Someday, 주간 리뷰, 히스토리, 설정의 웹 조회 기능을 네이티브 앱으로 이관한다.

## 구현한 내용

- Someday 항목, 최근 행동·오늘 계획·주간 회고 기록을 조회한다.
- 주간 리뷰에서 미검토 Inbox와 활성 프로젝트, 최근 회고를 함께 표시한다.
- 프로필 표시 이름과 제한·기본값을 조회한다.
- iPhone 더보기 탭과 Mac 사이드바에 진입점을 추가했다.
